# Guess The Mess

A multiplayer drawing-and-guessing game for 2–5 players.

## Download and host

1. Open this repository’s Releases section.
2. Download GuessTheMess.exe.
3. Run it on a Windows 10/11 x64 PC.
4. Keep the server console open.
5. Create a room and share its invite with players.

Python does not need to be installed when using the EXE.

## Join a game

Players only need a browser and the host’s invite.

For LAN play, use the same network.
For cross-network play, connect through Tailscale.
